# faqirchand_website_clone
A responsive bookstore e-commerce UI inspired by Delhi's iconic Khan Market bookshop, built with HTML, CSS &amp; JS.

## 🔗 Live Demo
[View Live Site](https://bhoomirawat.github.io/faqirchand_website_clone/)

## Features
- Responsive book grid with hover overlays (quick add / wishlist)
- Genre filter chips
- New arrivals list & featured banner section
- Testimonials, FAQ accordion, and newsletter signup sections
- Fully responsive layout (mobile, tablet, desktop)

## Tech Stack
- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (genre filtering, wishlist toggle)
